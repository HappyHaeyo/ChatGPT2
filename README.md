# ChatGPT2

캐릭터 기반 건강 관리 **웹 앱**입니다. 로컬에서 바로 실행해서 브라우저/모바일에서 볼 수 있습니다.

## 웹 앱으로 실행하기
1. 프로젝트 폴더에서 서버 실행
```bash
python3 -m http.server 4173
```
2. 브라우저에서 열기
- PC: `http://localhost:4173`
- 같은 와이파이의 모바일: `http://<내-PC-IP>:4173`

## 메뉴 구성 (Bottom Navigation)
- 캐릭터: 이름/성격/이미지 에셋 설정
- 채팅: 캐릭터와 오늘 상태 대화
- 루틴: 약/물/운동 체크
- 결과표: 아침/점심/저녁 기록 + 오늘 정산/이력 확인

## 24시간 자동 정산
- 앱 실행 시 날짜가 바뀌어 있으면 전날 데이터를 자동으로 결과 이력에 저장하고,
  오늘 기준으로 루틴/식단을 초기화합니다.
- 최근 14일 정산 기록을 보관합니다.
