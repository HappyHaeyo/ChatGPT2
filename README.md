# ChatGPT2

캐릭터 기반 건강 관리 웹앱입니다. 요청하신 모바일 스타일에 맞춰 **하단 내비게이션 바** 중심으로 구성했습니다.

## 메뉴 구성 (Bottom Navigation)
- 캐릭터: 이름/성격/이미지 에셋 설정
- 채팅: 캐릭터와 오늘 상태 대화
- 루틴: 약/물/운동 체크
- 결과표: 아침/점심/저녁 기록 + 오늘 정산/이력 확인

## 24시간 자동 정산
- 앱 실행 시 날짜가 바뀌어 있으면 전날 데이터를 자동으로 결과 이력에 저장하고,
  오늘 기준으로 루틴/식단을 초기화합니다.
- 최근 14일 정산 기록을 보관합니다.
